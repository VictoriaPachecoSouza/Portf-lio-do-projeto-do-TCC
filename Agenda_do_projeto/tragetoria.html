Tecnologias Utilizadas

Saiba o que cada uma faz dentro do site

HTML5

O HTML5 é a estrutura básica de qualquer site, funcionando como o esqueleto de uma casa.

CSS

O CSS (Cascading Style Sheets, ou Folhas de Estilo em Cascata) é a tecnologia usada para dar estilo, beleza e layout a uma página de internet.

JavaScript

O JavaScript é uma linguagem de programação usada para tornar páginas da internet interativas e dinâmicas.




O Desafio

Muitas pessoas perdem o foco no dia a dia devido a ferramentas de gestão complexas. O objetivo foi criar uma interface minimalista e direta.

✓
Interface simples Uma experiência fácil de compreender.
◇
Organização Informações apresentadas de forma clara.
◎
Usabilidade Foco nas necessidades do usuário.

Linha do Tempo do Desenvolvimento

Semana 1

Concepção & Wireframes

Desenho da arquitetura de informação e criação dos primeiros protótipos de baixa fidelidade para definir a jornada do usuário.

Semana 2

Estruturação e Estilização

Foco na escrita de um HTML5 semântico e acessível, seguido pela estilização com CSS moderno (Grid e Flexbox), garantindo responsividade.

Semana 3

Interatividade e Testes

Implementação das funções de adicionar e remover tarefas com JavaScript puro. Realização de testes de usabilidade em navegadores diferentes.



Desafios & Aprendizados

O maior desafio foi manipular o armazenamento local do navegador (LocalStorage) para salvar os dados do usuário. Superar esse obstáculo ajudou a compreender melhor a persistência de dados no Front-end.



Resultados

O projeto foi concluído no prazo e apresenta uma boa performance nos testes realizados.
